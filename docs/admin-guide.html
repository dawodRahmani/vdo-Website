VDO Admin Panel — User Guide

A walkthrough of every section in the VDO admin panel and what each lets you change on the public website.

Getting started

Sign in: visit /login on the website and sign in with an admin account.
Admin home: after login, the admin panel is reachable at /admin.
Permissions: only users with the admin role see the admin sidebar items below. Regular users only see the Dashboard.

Home Page

Sidebar: Home Page

Hero strip — slides

The top photo strip is now a slider. Each slide is a row of 3 photos.

  • Add slide button creates a new empty slide.
  • Each slide has 3 photo upload slots, alt text per photo, Order (sequence), and Active toggle.
  • Save slide applies changes; Delete removes it.
With 2 or more active slides, the strip becomes a slider that auto-advances every 6 seconds and shows ← / → arrows and dot indicators. With 1 slide it stays static (same as before).

Key Impact Numbers

Each stat row (e.g. "Regions", "Lives Impact") has:

  • Label text
  • SVG/icon upload
  • Size scale slider (50–200%)

Strategic Priority Areas (5 cards)

  • Title, link URL, icon SVG, size scale.

Regions & Provinces image

  • Upload the image (SVG/PNG/JPG/WEBP).
  • Alt text.
  • Width slider 30–100% so you can shrink/enlarge it inside its column.

Our Commitment icons (12 cards)

  • Each icon's image upload and size scale.

About Page

Sidebar: About Page

Every paragraph and heading on About Us is editable as plain text. Paragraphs are separated by blank lines.

  • Executive Summary — heading, sub-heading, body
  • History — heading, body
  • Coordination outro paragraph
  • Mission — lead phrase, body
  • Vision — lead phrase, body
  • Looking Ahead — heading, sub-heading, body
Leaving a field empty restores the original default text. Clear it intentionally if you want the default back.

News & Announcements

Sidebar: News & Announcements

  • Create / edit / delete posts.
  • Fields: title, slug, category, body, cover image, published date.
  • Drafts vs published — only published posts appear on the public site.

Hero Sections

Sidebar: Hero Sections

The top 3-image strip on each non-home page. Each row corresponds to one page (e.g., About, Where We Work, etc.).

  • Upload 3 photos per page with alt text.
For the home page hero, use Home Page → Hero strip — slides instead. Hero Sections still drives the strip on all other pages.

Donate

Sidebar: Donate

Manage the cards displayed on the Donate page.

  • Create / edit / delete items.
  • Kind: intro, cause, or method.
  • Icon name (Lucide icon), title, body text, order, active toggle.

Media

Sidebar: Media

The Media page has three sections: Documentaries, Program Snapshots, and Publications.

Documentaries

  • Title
  • YouTube URL (paste a link) or Upload video file (mp4/webm/mov, up to 100 MB) — if both, the uploaded file wins.
  • Thumbnail image (shown on the card before play).
  • Order & Active toggle.
Clicking a documentary card on the public site opens an in-page modal player (YouTube embed for links, HTML5 video for uploaded files). The thumbnail is used as the poster image.

Program Snapshots (Photos)

  • Upload photos one at a time.
  • Order determines which photo-mosaic page it appears on (6 per page).

Publications

  • Title, cover image (used as download).
  • Card size per item (40–150%). Layout is always 4 per row with a slider for overflow.

Opportunities

Sidebar: Opportunities

Categories (4 fixed cards)

Jobs, Bids, Volunteer, Participation. For each:

  • Icon image, title, body description, order, active.

Current Listings

  • Add listing — category, title, reference, summary, location, deadline, order.
  • Edit or delete existing listings.

Our Commitment

Sidebar: Our Commitment

Commitments (12 by default — add / remove freely)

  • Slug (URL anchor), title, body (paragraphs separated by blank lines).
  • Card icon SVG/PNG upload (with preview).
  • Order, active toggle.

Publications

  • Add / edit / delete publications with title and cover image.

"Make a Report" form on the public page

The form (Subject, Comment, Attachment up to 5 MB) emails the configured destination via SMTP. See Email Settings.

Where We Work

Sidebar: Where We Work

Manage the 6 region sections (or more — fully CRUD).

  • Slug (URL anchor), title, subtitle, body (paragraphs), order, active.
  • Map image upload (SVG/PNG/JPG/WEBP).
  • Video URL — YouTube link renders as an embedded iframe; any other URL renders an HTML5 video.
  • Map on right toggle — flips the layout per region.

Email Settings

Sidebar: Email Settings

Report destination

Email address that receives submissions from the public Make a Report form (Our Commitment page).

From identity

From address & from name used in outgoing email envelopes.

SMTP server

FieldNotes
DriverSMTP (production) or Log (testing — writes to storage/logs/laravel.log instead of sending).
EncryptionNone, TLS, SSL, or STARTTLS.
Host / Porte.g. smtp.gmail.com / 587.
UsernameAccount that sends the email.
PasswordStored encrypted. Leave blank when editing to keep the existing one.

Send a test email

Use the "Send test" button to verify SMTP — it sends a small test message to the address you enter.

Users

Sidebar: Users

  • Add user — name, email, role (Admin or User), password + confirm.
  • Edit name, email, role (cannot edit your own role).
  • Change password (no current-password required — admin-set).
  • Delete user (cannot delete your own account).
You cannot demote yourself out of admin or delete your own account, so you can't accidentally lock yourself out.

Page Colors

Sidebar: Page Colors

Set the body background color for each public page (Home, About, Where We Work, etc.). Each route has its own color picker.

Strategic Priorities

Sidebar: Strategic Priorities (collapsible group called Pages)

Overview (Hub Cards)

The 5 hub cards shown on /strategic-priorities. Edit each card's title, href, icon name, and description.

Individual pages (10)

Education, Economic Growth, Rural Development, Health and Nutrition, Emergency Response, Cross-Cutting Areas, Target Group, Secondary Beneficiaries, Tertiary Audience, Contribution Project.

Each page exposes the same editable fields:

FieldShown as
HeadingPage title (with icon).
BodyParagraphs before the main image. Blank lines split paragraphs.
Main infographic imageSVG/PNG uploaded centerpiece + alt text.
Between-body textParagraphs shown between the infographic and the bullets. Supports **bold**.
Achievements headinge.g., "Key Achievements:".
BulletsAdd, edit, delete one bullet at a time.
Beneficiary stats imageOptional secondary image (donut chart / breakdown) + alt text.
Every field is optional — sections that you leave empty simply don't render on the public page.

VDO's Resilience

Sidebar group with 4 sub-pages: Our Capacity, Policies, Programmatic Approach, Collective Resilience.

  • Add / edit / delete items in each section.
  • Each item: title, body, optional icon/image upload, order, active.

Header & Footer

Sidebar group with two items.

Header

  • Logo — upload PNG/JPG/SVG (max 4 MB). Remove button reverts to the default.
  • Logo height (px) — slider 24–200, default 72. Live preview shows the chosen size.

Footer

  • Contact info — phone & email. Shared with the header top bar (if you ever re-enable it).
  • Social media URLs — Facebook, X (Twitter), LinkedIn, YouTube. Each renders only if filled.
  • Newsletter heading — text above the newsletter form.
  • Donate button — text and destination URL.

General tips

  • Image uploads generally accept PNG, JPG, WEBP, and SVG. Logo / icons up to ~4 MB; hero photos up to ~8 MB; documentary videos up to 100 MB.
  • Order fields control display sequence on the public page. Lower number = earlier.
  • Active toggles hide an item from the public site without deleting it.
  • Paragraphs in body fields are separated by blank lines, not single line breaks.
  • Bold emphasis in "between body" fields uses **text**.
  • Saving takes effect immediately — refresh the public page to see the change. Inertia.js handles all navigation, so no full page reload is needed in the admin.
